## 🚀 Selected Projects

### Project 1: VPC Network Architecture (Intermediate)
**Goal:** Build a production-ready virtual private cloud network with public/private subnets, NAT Gateway, and proper security controls.

**Key Learnings:**
- Virtual Private Cloud (VPC) design and implementation
- Public & Private Subnet configuration
- Security Groups and Network ACLs
- NAT Gateway setup for private subnet internet access
- High-availability across Availability Zones

### Project 2: Infrastructure as Code - Terraform (Intermediate–Advanced)
**Goal:** Manage complete cloud infrastructure through code using Terraform, with modular architecture and CI/CD integration.

**Key Learnings:**
- Terraform module development
- Remote state management with S3/DynamoDB
- Infrastructure versioning and collaboration
- CI/CD pipeline integration for infrastructure deployment
- Cost optimization through infrastructure as code
